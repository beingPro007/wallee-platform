# Wallee Admin

Next.js uploader, collection management, image moderation, and desktop approval interface.

Run `make admin-install` and `make admin-dev` from the repository root. Preserve existing local `.env` and `.env.local`; on a fresh checkout use `.env.example` as a template. See the root `docs/environment.md` for public versus server-only configuration and `docs/deployment.md` for the Vercel root-directory change.

Commands: `npm run dev`, `npm run typecheck`, `npm run build`, `npm start`.
